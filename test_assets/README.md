# Test assets

- `synthetic/`: generated by `npm run assets` (`tools/make_test_assets.js`). The output
  is deterministic and the designs are original. The characters (1200x1600
  straight-alpha cels plus premult/green-screen/tight-crop variants) and `manifest.json`
  are committed. The backgrounds (13 stills + a 48-frame fire sequence, ~110 MB) are
  **not** committed: regenerate them with `npm run assets -- --only bgs` and
  `npm run assets -- --only fire`.
- `private/`: **gitignored**. Drop real frames here for tuning (`private/refs/` for
  reference looks). Never commit them, or any render made from them.

Preview: `docs/img/synthetic_assets.png`.
